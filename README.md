# 📚 Student Productivity Hub

## 🚀 Overview  
Student Productivity Hub is an intuitive web application designed to help students streamline their daily tasks, manage time effectively, and improve overall productivity.  

It combines essential tools like a Pomodoro timer, notes manager, and task tracker into one centralized platform.

---

## ✨ Features  

- ⏱️ Pomodoro Timer  
  Stay focused using the Pomodoro technique (25-minute sessions with breaks).

- 📝 Notes Management  
  Create, edit, and delete notes easily.

- ✅ Task Manager (To-Do List)  
  Organize tasks and track progress.

- 🎨 Modern UI  
  Clean and responsive design for a better user experience.

---

## 🛠️ Tech Stack  

- HTML  
- CSS  
- JavaScript  
- LocalStorage (for saving data)
